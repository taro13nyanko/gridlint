What it actually does

  1. Reads the formulas, not the picture

    Every formula is parsed into a syntax tree and linked into a dependency graph, so Gridlint knows which cells feed which.

  2. Recalculates the whole workbook

    Then it checks its own arithmetic against the values Excel or Sheets saved in the file. If those disagree, it says so instead of guessing.

  3. Ranks defects by money, not by count

    Each fix is applied to a copy, the workbook is recomputed, and the difference is measured. The number you see was calculated, not estimated.

  4. Explains it to whoever owns the file

    A language model writes the plain-English note. It never decides what is wrong and never produces a number: any figure it cannot source from the evidence is rejected.
